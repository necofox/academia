if y else: el semáforo

Hasta ahora tus programas hacían siempre lo mismo, línea por línea. Con un condicional, el programa elige un camino según una condición, como tú frente a un semáforo: si está en verde, avanzas; si no, esperas.

if (condición) {
  // se ejecuta si la condición es true
} else {
  // se ejecuta si es false
}
  • La condición va entre paréntesis y es una comparación que da true o false, como las de la clase pasada.
  • Las llaves agrupan el código de cada camino.
  • El código de adentro se escribe con sangría, unos espacios a la derecha, para que se lea mejor.
  • else es opcional: si no lo pones y la condición es falsa, simplemente no pasa nada.

Error clásico: escribir un solo igual dentro del if. Un igual guarda un valor, no compara. Para comparar, usa siempre tres iguales.

Práctica

Ejecuta. Luego cambia la edad a 15 y vuelve a ejecutar: el programa toma el otro camino.

Varias opciones: else if

Cuando hay más de dos caminos, encadenas condiciones con else if. JavaScript las revisa de arriba hacia abajo y ejecuta solo la primera que sea verdadera. Por eso el orden importa: pon primero la condición más exigente.

Condiciones combinadas: un login

Con y lógico y o lógico puedes exigir varias cosas a la vez. Un inicio de sesión, por ejemplo, exige que el usuario y la contraseña sean correctos al mismo tiempo.

Seguridad: fíjate que el mensaje de error no dice cuál de los dos datos falló. Si dijera "la contraseña es incorrecta", un atacante sabría que el usuario sí existe. Las páginas seguras siempre dicen "usuario o contraseña incorrectos".

Y un aviso importante: en una página real, la contraseña nunca se revisa así en JavaScript del navegador, porque cualquiera puede leer ese código con F12. Se revisa en el servidor. Esto es solo para practicar la lógica.

switch y el operador ternario

Cuando comparas una misma variable con muchos valores exactos, switch se lee más ordenado que muchos else if. Cada caso termina con break, para que no siga con el siguiente. default es el camino si ningún caso coincide.

El operador ternario es un if de una sola línea: condición, signo de pregunta, valor si es verdad, dos puntos, valor si es falso. Úsalo solo para decisiones cortas.

Resumen de la clase

Conceptos que debes recordar

  • if ejecuta un bloque si la condición es verdadera; else, si no lo es.
  • else if encadena opciones: se revisan de arriba hacia abajo y solo se ejecuta la primera verdadera. Por eso el orden importa.
  • Con && y || se combinan condiciones, como en un inicio de sesión que exige usuario y contraseña correctos.
  • Por seguridad, el mensaje de error de un login no dice cuál de los dos datos falló.
  • switch compara una variable con varios valores exactos; cada caso termina con break y default cubre el resto.
  • El operador ternario es un if corto: condición ? valorSiSí : valorSiNo.

Ya deberías ser capaz de

  • Hacer que un programa elija entre varios caminos.
  • Combinar condiciones con && y ||.
  • Elegir entre if, switch y el operador ternario.

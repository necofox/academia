Variables y tipos de datos

Guarda información en variables con let y const, conoce los tipos de datos y úsalos en cálculos. Duración: 2 horas.

Repaso de la Clase 01

¿Qué es una variable?

Una variable es una caja con una etiqueta. Guardas algo dentro y, cuando lo necesitas, lo buscas por el nombre de la etiqueta. Así tu programa recuerda datos: un nombre, una edad, un total.

let edad = 25;
│   │    │ └── el valor que guardas
│   │    └──── "guarda en"
│   └───────── el nombre de la caja
└───────────── crear una caja que puede cambiar

let y const

  • let: crea una caja cuyo contenido puede cambiar después. Por ejemplo, una edad que aumenta cada año.
  • const: crea una caja sellada: su valor no se puede reemplazar. Por ejemplo, tu fecha de nacimiento.
  • Regla de buenos programadores: usa const siempre que puedas, y let solo si el valor va a cambiar.
  • Quizá veas var en código antiguo. Es la forma vieja: no la uses.

Cómo nombrar las variables

  • Usa nombres que expliquen qué guardan: precioTotal es mejor que x.
  • Si el nombre tiene varias palabras, se juntan y cada palabra nueva empieza con mayúscula: nombreCompleto, fechaDeNacimiento. Esto se llama camelCase, por las jorobas del camello.
  • No pueden empezar con un número, no llevan espacios ni tildes, y distinguen mayúsculas: edad y Edad son cajas distintas.

Para cambiar el valor de una variable creada con let, escribes su nombre, el signo igual y el nuevo valor, sin volver a poner let.

Tipos de datos

No todo lo que guardas es igual: un nombre es texto, una edad es un número, una respuesta de sí o no es otra cosa. Cada tipo se comporta distinto.

TipoQué guardaEjemplo
stringTexto, siempre entre comillas."Hola", 'Lima'
numberNúmeros enteros o con decimales (con punto).25, 3.5
booleanSolo dos valores: verdadero o falso.true, false
undefinedUna caja creada pero vacía.let algo;
null"Vacío a propósito": no hay valor.let ganador = null;

Con la palabra typeof puedes preguntarle a JavaScript qué tipo de dato es algo.

Dato curioso: typeof null responde "object". Es un error que tiene JavaScript desde 1995 y que nunca se corrigió para no romper las páginas antiguas.

Usar variables en cálculos

La gracia de las variables es combinarlas. Puedes multiplicar un precio por una cantidad y guardar el resultado en otra variable. Si cambias el precio, el resultado cambia solo.

Con textos, el signo más los une: "Hola, " más nombre forma "Hola, Ana". A esto se le llama concatenar.

Errores comunes con variables

  • Cambiar una const: da TypeError, Assignment to constant variable, que significa "asignación a una variable constante".
  • Escribir mal el nombre: da ReferenceError, is not defined. Recuerda: Ciudad y ciudad son distintas.
  • Crear dos veces la misma variable con let: da SyntaxError, has already been declared, que significa "ya fue declarada".

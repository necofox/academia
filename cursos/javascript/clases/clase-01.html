¿Qué es programar?

Programar es escribir instrucciones para que una computadora haga algo. Parece fácil, pero hay un detalle: la computadora es muy rápida, pero no piensa. Hace exactamente lo que le dices, ni más ni menos.

El experimento del sándwich

Imagina que le explicas a un robot cómo hacer un sándwich y le dices: "pon la mantequilla en el pan". El robot podría poner el pote de mantequilla entero encima del pan, ¡sin abrirlo! Porque no le dijiste que lo abra, que use un cuchillo y que la unte.

Programar es aprender a dar instrucciones tan precisas que no quede ninguna duda. A esa lista ordenada de pasos para resolver un problema se le llama algoritmo.

Algoritmo: una secuencia de pasos claros y ordenados para resolver un problema. Una receta de cocina es un algoritmo. Las instrucciones para armar un mueble también.

¿Qué es un lenguaje de programación?

La computadora, por dentro, solo entiende unos y ceros. Nosotros no podemos escribir así, por eso existen los lenguajes de programación: idiomas a mitad de camino entre el humano y la máquina. Escribes en el lenguaje y un programa especial lo traduce para la computadora.

Hay muchos lenguajes: JavaScript, Python, Java, C, Kotlin… Cada uno es mejor para ciertas cosas, pero todos comparten las mismas ideas básicas. Si aprendes bien uno, aprender el siguiente es mucho más fácil.

¿Y qué es un bug?

Un bug es un error en un programa. La palabra significa "bicho" en inglés. Se hizo famosa en 1947, cuando unos ingenieros encontraron una polilla atrapada dentro de una computadora que fallaba, y la pegaron en su cuaderno de notas. Hoy, encontrar y arreglar bugs se llama depurar, y es parte del trabajo diario de todo programador.

¿Qué es JavaScript?

JavaScript es el lenguaje de programación de la web. Cada vez que una página reacciona a lo que haces, como un botón que abre un menú, un formulario que te avisa que falta un dato o un chat que se actualiza solo, casi siempre hay JavaScript trabajando.

Los tres idiomas de una página web

Toda página web se construye con tres lenguajes que trabajan juntos. Piensa en una persona:

HTML = el esqueleto

Define la estructura y el contenido: títulos, párrafos, imágenes, botones.

CSS = la ropa y el estilo

Define cómo se ve: colores, tamaños, tipos de letra, posiciones.

JavaScript = los músculos y el cerebro

Define el comportamiento: qué pasa cuando haces clic, cálculos, mostrar u ocultar cosas.

¿Dónde se ejecuta JavaScript?

  • En el navegador: Edge, Chrome, Firefox y Safari traen un "motor" que entiende JavaScript. No necesitas instalar nada para empezar.
  • Fuera del navegador, con Node.js: sirve para crear servidores, APIs y herramientas. Lo veremos en el nivel 4 del curso.
  • En celulares y computadoras: con herramientas especiales también se hacen apps con JavaScript.

Ojo: Java y JavaScript no son el mismo lenguaje, aunque sus nombres se parezcan. Es como "carro" y "carroza": comparten un pedazo del nombre, pero son cosas distintas. El parecido fue una decisión de marketing de los años noventa.

La consola y tu primer código

La consola es la ventana donde los programadores ven mensajes de su código. Para escribir algo en la consola usamos esta instrucción:

console.log("Hola, mundo");

Vamos a leerla por partes:

  • console es la consola.
  • El punto significa "de la consola, usa…".
  • log significa "registrar" o "anotar". Es la acción de escribir un mensaje.
  • Lo que va entre paréntesis es lo que quieres mostrar.
  • El punto y coma del final marca el fin de la instrucción, como el punto al final de una oración.

Textos y números

Los textos van siempre entre comillas, por ejemplo "Hola". En programación a los textos se les llama strings, que significa "cadenas", porque son cadenas de letras. Los números van sin comillas, y con ellos puedes hacer cálculos.

CódigoLo que muestraPor qué
console.log(2 + 3);5Son números: JavaScript calcula.
console.log("2 + 3");2 + 3Está entre comillas: es un texto y se muestra tal cual.
console.log("Edad:", 25);Edad: 25Con una coma puedes mostrar varias cosas juntas, separadas por un espacio.
console.log(10 * 3);30El asterisco multiplica y la barra / divide.

Comentarios

Si escribes dos barras, todo lo que sigue en esa línea es un comentario. La computadora lo ignora: sirve para dejar notas a las personas que leen el código, incluido tu yo del futuro.

Importante: JavaScript distingue mayúsculas y minúsculas. console.log funciona, pero Console.log o console.Log dan error.

Leer errores: tu nuevo superpoder

Los principiantes se asustan con los mensajes de error en rojo. Los programadores con experiencia se alegran, porque el error les dice exactamente qué falló y muchas veces dónde. Aprende a leerlos con calma.

ReferenceErrorUsaste un nombre que no existe, casi siempre por escribirlo mal.consol.log("Hola");
TypeErrorUsaste algo de una forma que no se puede. Lo verás más adelante.console.log.hola();

El método para arreglar errores

  • Lee el nombre del error: ya te dice qué tipo de problema buscar.
  • Lee el mensaje completo, aunque esté en inglés: busca palabras clave como missing, que significa "falta", o not defined, que significa "no definido".
  • Arregla un error a la vez y vuelve a ejecutar. A veces un error esconde otro.

Retos: programa tú solo

Ahora escribes tú el código desde cero. Si fallas, te daré una pista; a los tres intentos te muestro una solución posible.

Reto 1: tu tarjeta de presentación

Muestra 3 líneas en la consola. La primera debe ser exactamente === MI TARJETA ===. La segunda, tu nombre, por ejemplo Nombre: Ana. La tercera, exactamente Curso: JavaScript.

Reto 2: ¿cuántos minutos tiene un día?

Muestra solo el número de minutos de un día. Haz que JavaScript lo calcule multiplicando las horas por los minutos: no escribas el resultado a mano.

# Curso de Python — cómo darlo

> **Norma principal:** `PROMPT-MAESTRO.md` (información verificada con fuentes, estructura de
> 9 secciones, control de calidad y no publicar sin autorización). Si algo de este archivo lo
> contradice, manda el prompt maestro.

Objetivo: aprender **desarrollo de software** desde cero con Python: programas,
automatización, APIs, bases de datos y proyectos reales. Empiezo sin saber programar.

## Al empezar cada clase

1. Lee `progreso.md` y `ruta-aprendizaje.md`.
2. Repaso rápido de la clase anterior (si es la primera, sáltalo).
3. Sigue con la lección que toca, o la que yo elija en el menú.

## Formato de cada clase (HTML interactivo, ver `CLAUDE.md`)

1. **Objetivo**: qué sabré construir o entender al terminar.
2. **Explicación sencilla** con analogía antes del término técnico, con voz.
3. **Código de ejemplo** comentado línea por línea en español.
4. **Práctica**: escribo y ejecuto el código en mi propia computadora (Python ya está
   instalado en mi PC) con Visual Studio Code o la terminal. La página trae el código
   para copiar y lo que debería salir en pantalla.
5. **Reto**: un pequeño programa que hago solo. Pistas antes que la solución.
6. **Inglés técnico del día**: 5–8 palabras del código (print, input, list…).
7. **Mini-examen** y **apuntes en Word** en `apuntes/NN-tema.docx`.
8. **Actualiza `progreso.md`**.

## Herramientas

- Python (ya instalado), Visual Studio Code (ya instalado) y la terminal.
- Los programas de práctica van en `cursos/python/proyectos/`.
- Antes de usar `pip`, explícame qué es un entorno virtual (`venv`) y por qué usarlo.

## Estilo

- Primero que funcione, después la teoría fina. Nada de memorizar sin practicar.
- Errores = aprendizaje: enséñame a leer un *traceback* de abajo hacia arriba.
- Buenas prácticas desde el inicio: nombres claros, funciones pequeñas, código legible (PEP 8).

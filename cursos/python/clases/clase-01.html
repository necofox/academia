¿Qué es Python? Instalación y tu primer programa

Conoce Python, verifica que está listo en tu computadora, prueba el modo interactivo y crea tus primeros programas de verdad con Visual Studio Code. Duración: 2 horas.

Bienvenida

¡Bienvenido a tu primera clase de Python! Hoy vas a programar en tu propia computadora, con las mismas herramientas que usan los desarrolladores profesionales.

Al terminar esta clase podrás:

  • Explicar qué es Python y para qué se usa.
  • Comprobar tu instalación de Python y preparar Visual Studio Code.
  • Usar el modo interactivo de Python para hacer cálculos.
  • Crear, guardar y ejecutar tus propios archivos de Python.
  • Leer los mensajes de error más comunes.

Cómo practicar en esta clase

Vas a trabajar con dos ventanas: esta página para leer y escuchar, y tu computadora para programar. Si tienes una sola pantalla, pon esta página a un lado y Visual Studio Code al otro: arrastra cada ventana hacia un borde de la pantalla.

¿Qué es programar y qué es Python?

Programar es escribir instrucciones precisas para que una computadora haga algo. La computadora es muy rápida pero no piensa: hace exactamente lo que le dices. Una lista ordenada de pasos para resolver un problema se llama algoritmo, como una receta de cocina.

Python es un lenguaje de programación creado por Guido van Rossum y publicado en 1991. Su nombre no viene de la serpiente, sino de un programa de comedia británico llamado Monty Python.

¿Por qué Python es tan popular?

  • Se lee casi como inglés: es uno de los lenguajes más fáciles para empezar.
  • Sirve para casi todo: páginas web y APIs, automatizar tareas aburridas, análisis de datos, inteligencia artificial y ciberseguridad.
  • Tiene miles de librerías: código ya hecho por otros que puedes usar gratis.
  • Lo usan empresas enormes: por ejemplo, Instagram está construido en gran parte con Python.

¿Cómo funciona?

Python es un lenguaje interpretado. Escribes tu programa en un archivo de texto que termina en punto p y, y otro programa llamado intérprete lo lee línea por línea y lo ejecuta. Ese intérprete es lo que instalaste en tu computadora cuando instalaste Python.

Prepara tu computadora

Buenas noticias: tu computadora ya tiene Python instalado. Vamos a comprobarlo y a preparar tu editor de código.

Paso 1: comprobar Python

Pulsa la tecla Windows, escribe PowerShell y ábrelo. Luego copia este comando, pégalo con clic derecho y pulsa Enter:

python --version

Deberías ver algo como esto (el número exacto puede cambiar):

Python 3.12.x

¿Te sale un error o se abre la Microsoft Store? Prueba con este otro comando, que usa el lanzador de Python para Windows:

py --version

Paso 2: preparar Visual Studio Code

Visual Studio Code, o VS Code, es el editor donde escribirás tus programas. También ya está instalado en tu computadora.

  • Abre VS Code.
  • Pulsa Control más Shift más X para abrir las extensiones.
  • Busca Python y elige la extensión cuyo autor es Microsoft. Pulsa Instalar. Esto le enseña a VS Code a entender Python.
  • Ve al menú Archivo, Abrir carpeta, y elige: Escritorio, Cyberseguridad, cursos, python, proyectos. Ahí guardarás todos tus programas.
  • Abre la terminal de VS Code con el menú Terminal, Nuevo terminal. Aparecerá abajo, ya ubicada en tu carpeta de proyectos.

¿Qué es la terminal? Es la misma "pantalla negra" de PowerShell, pero dentro de VS Code. Desde ahí ejecutarás tus programas.

El modo interactivo: Python como calculadora

Python tiene un modo interactivo. Escribes una instrucción, pulsas Enter y te responde al instante. Sirve para probar ideas rápidas. Sabrás que estás en ese modo porque aparece el símbolo de tres signos mayor que.

Primero practica en esta simulación. Después lo harás en tu computadora real.

SímboloOperaciónEjemploResultado
+ -Suma y resta2 + 35
*Multiplicación4 * 520
/División (siempre da decimal)7 / 23.5
//División entera (sin decimales)7 // 23
%Resto de la división7 % 21
**Potencia2 ** 38

Ojo con los decimales: en Python, como en inglés, los decimales se escriben con punto y no con coma. Tres y medio se escribe 3.5.

Ahora en tu computadora: en la terminal de VS Code escribe python y pulsa Enter. Aparecerá >>>. Repite ahí las misiones. Para salir del modo interactivo escribe exit().

Tu primer programa de verdad

El modo interactivo olvida todo al cerrarse. Los programas de verdad se guardan en archivos para usarlos las veces que quieras.

Paso 1: crear el archivo

En VS Code, en el panel izquierdo, pulsa el icono de nuevo archivo y llámalo hola punto p y. La extensión punto p y le dice a la computadora que es un programa de Python.

Paso 2: escribir el código

Copia este código en el archivo y cambia la segunda línea por tu nombre. Luego guarda con Control más S.

# Mi primer programa en Python
print("¡Hola, mundo!")
print("Me llamo ____ y estoy aprendiendo Python")
print("2 + 3 =", 2 + 3)
  • La línea que empieza con numeral es un comentario: Python la ignora.
  • La función print muestra en pantalla lo que pongas entre paréntesis. Su nombre significa "imprimir".
  • Los textos van entre comillas. En programación se llaman strings.
  • Con una coma puedes mostrar varias cosas juntas, y Python las separa con un espacio.

Paso 3: ejecutarlo

En la terminal de VS Code escribe este comando y pulsa Enter:

python hola.py

Deberías ver:

¡Hola, mundo!
Me llamo ____ y estoy aprendiendo Python
2 + 3 = 5

Atajo: con la extensión de Python instalada, también puedes pulsar el botón ▷ que aparece arriba a la derecha en VS Code.

Reto 1: tarjeta.py

Crea un archivo tarjeta.py que muestre tu tarjeta de presentación en 4 líneas: una línea de adorno, tu nombre, tu ciudad y el curso. Ejemplo de salida:

==== MI TARJETA ====
Nombre: Ana
Ciudad: Lima
Curso: Python

Reto 2: tiempo.py

Crea un archivo tiempo.py que calcule, sin escribir los resultados a mano, cuántas horas tiene una semana, cuántos minutos tiene un día y cuántos segundos tiene una hora. Ejemplo de salida:

Horas en una semana: 168
Minutos en un día: 1440
Segundos en una hora: 3600
Ver una pista

Usa una coma entre el texto y el cálculo: print("Horas en una semana:", 7 * 24)

Leer errores en Python

Cuando algo falla, Python muestra un mensaje llamado traceback, que significa "rastro". Truco de experto: léelo de abajo hacia arriba. La última línea dice qué tipo de error es y por qué. Las líneas de arriba dicen en qué archivo y en qué línea ocurrió.

ErrorQué significaEjemplo
SyntaxErrorAlgo está mal escrito: falta una comilla o un paréntesis.print("Hola)
NameErrorUsaste un nombre que no existe, casi siempre por escribirlo mal.prin("Hola")
IndentationErrorHay espacios de más o de menos al inicio de una línea. print("Hola") con espacios al inicio

Los espacios importan: en Python, los espacios al inicio de una línea tienen significado. Por ahora, escribe cada instrucción pegada al borde izquierdo. Más adelante aprenderás cuándo sí se usan.

Resumen de la clase

Conceptos que debes recordar

  • Programar es dar instrucciones precisas; un algoritmo es una lista ordenada de pasos.
  • Python es un lenguaje interpretado, interactivo y orientado a objetos, muy usado por lo fácil que es de leer.
  • El modo interactivo (símbolo >>>) responde al instante: sirve como calculadora y para probar ideas.
  • Los programas de verdad se guardan en archivos .py y se ejecutan desde Visual Studio Code.
  • print(...) muestra un mensaje en la pantalla.
  • Los errores (traceback) se leen de abajo hacia arriba: la última línea dice qué tipo de error ocurrió.

Ya deberías ser capaz de

  • Comprobar que Python está listo en tu computadora.
  • Crear y ejecutar un programa en un archivo .py.
  • Leer un mensaje de error de Python.

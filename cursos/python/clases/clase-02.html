Repaso de la Clase 01

Variables: cajas con nombre

Una variable es una caja con una etiqueta donde guardas un dato para usarlo después. En Python crearla es facilísimo: escribes el nombre, el signo igual y el valor. No hace falta ninguna palabra especial antes.

nombre = "Ana"
edad = 25

El signo igual en programación no significa "es igual a": significa "guarda esto en". Para cambiar el valor, simplemente vuelves a asignar.

Reglas para los nombres

  • En Python, si el nombre tiene varias palabras, se separan con guion bajo: nombre_completo, precio_total. Este estilo se llama snake_case, "estilo serpiente".
  • No pueden empezar con número, no llevan espacios ni tildes, y distinguen mayúsculas: edad y Edad son variables distintas.
  • Usa nombres que expliquen el contenido: precio_total es mejor que x.

Tipos de datos y conversiones

TipoQué guardaEjemplo
strTexto (string), entre comillas."Lima"
intNúmero entero (integer).25
floatNúmero con decimales, con punto.3.5
boolVerdadero o falso, con mayúscula inicial.True, False

La función type te dice el tipo de cualquier dato.

Convertir de un tipo a otro

  • int("5") convierte el texto "5" en el número 5.
  • float("3.5") lo convierte en decimal.
  • str(25) convierte el número 25 en el texto "25".

Python no mezcla texto y números: si intentas sumar "5" más 3, da TypeError. Primero hay que convertir. Es más estricto que JavaScript, y eso evita errores escondidos.

input(): tu programa pregunta

La función input muestra una pregunta, espera a que el usuario escriba y pulse Enter, y te devuelve lo que escribió. Así tus programas dejan de ser siempre iguales.

La regla de oro: input siempre devuelve texto, aunque el usuario escriba un número. Si necesitas hacer cálculos, conviértelo con int o float.

Programa 1: saludo.py

En VS Code, en tu carpeta de proyectos, crea el archivo saludo punto p y con este código, guárdalo y ejecútalo con python saludo punto p y.

nombre = input("¿Cómo te llamas? ")
print("Hola,", nombre, "¡bienvenido a Python!")

Si escribes Ana, deberías ver:

¿Cómo te llamas? Ana
Hola, Ana ¡bienvenido a Python!

Programa 2: edad.py

Aquí convertimos lo que escribe el usuario a número con int, para poder sumarle uno.

edad = int(input("¿Cuántos años tienes? "))
print("El próximo año tendrás", edad + 1, "años")
¿Cuántos años tienes? 25
El próximo año tendrás 26 años

Prueba quitar el int( ) y ejecútalo otra vez: verás el error de la siguiente sección.

Errores típicos de esta clase

  • TypeError: can only concatenate str (not "int") to str. Significa "solo puedo unir texto con texto, no con un número". Pasa al sumar texto y número.
  • ValueError: invalid literal for int(). Pasa cuando intentas convertir a número algo que no lo es, como int de "hola".
  • NameError: name is not defined. Usaste una variable que no existe o la escribiste mal.

Resumen de la clase

Conceptos que debes recordar

  • Una variable se crea con nombre, signo igual y valor: edad = 25. No hace falta ninguna palabra especial.
  • Tipos de datos: str (texto), int (entero), float (decimal, con punto) y bool (True o False, con mayúscula inicial).
  • type() te dice el tipo; int(), float() y str() convierten de un tipo a otro.
  • input() pregunta al usuario y siempre devuelve texto: para hacer cálculos, conviértelo primero.
  • Unir texto con un número da TypeError; convertir a número algo que no lo es da ValueError.

Ya deberías ser capaz de

  • Guardar datos en variables con nombres claros.
  • Hacer programas que preguntan y responden.
  • Convertir datos al tipo que necesitas.

Condicionales: if, elif y else

Tus programas toman decisiones. Aprende la sangría de Python, las condiciones combinadas y crea programas útiles. Duración: 2 horas.

Repaso de la Clase 03

if y la sangría

Un condicional hace que el programa elija un camino. Si la condición es verdadera, ejecuta un bloque de código; si no, lo salta.

edad = 20
if edad >= 18:
    print("Eres mayor de edad")
else:
    print("Eres menor de edad")

Las dos reglas de Python

  • Los dos puntos: la línea del if y la del else terminan con dos puntos.
  • La sangría: el código que pertenece al if va desplazado 4 espacios a la derecha. En otros lenguajes se usan llaves; Python usa los espacios. Por eso en la clase 1 viste que los espacios importan.

VS Code pone la sangría solo cuando pulsas Enter después de los dos puntos. Para volver al borde, borra los espacios.

Error clásico: escribir un solo igual en el if. Un igual guarda, dos iguales comparan. if edad igual 18 da SyntaxError; lo correcto es if edad igual igual 18.

Practica en tu computadora: mayor.py

edad = int(input("¿Cuántos años tienes? "))
if edad >= 18:
    print("Eres mayor de edad")
else:
    print("Eres menor de edad")
print("Gracias por usar el programa")

Ejecútalo dos veces, con 20 y con 15. La última línea no tiene sangría: se ejecuta siempre, sea cual sea el camino.

Varias opciones con elif

elif es la abreviatura de "else if": "si no, si…". Python revisa las condiciones de arriba hacia abajo y ejecuta solo la primera verdadera. Por eso conviene poner primero la más exigente.

nota = int(input("Tu nota (0 a 20): "))
if nota >= 18:
    print("Excelente")
elif nota >= 11:
    print("Aprobado")
else:
    print("Desaprobado")

Condiciones combinadas

Con and, or y not puedes combinar condiciones, y con in puedes preguntar si un texto contiene a otro.

usuario = input("Usuario: ")
clave = input("Contraseña: ")
if usuario == "admin" and clave == "S3gur4!":
    print("Bienvenido")
else:
    print("Usuario o contraseña incorrectos")

correo = input("Tu correo: ")
if "@" in correo and "." in correo:
    print("El correo parece válido")
else:
    print("Ese correo no es válido")

Seguridad: el mensaje de error no dice si falló el usuario o la contraseña, para no darle pistas a un atacante. Y en un sistema real, las contraseñas nunca se escriben dentro del código: se guardan cifradas con hash. Lo verás en el nivel 4.

Resumen de la clase

Conceptos que debes recordar

  • if ejecuta un bloque si la condición es verdadera; else, si no lo es.
  • Las dos reglas de Python: la línea del if termina con dos puntos, y el bloque va con sangría. Si falta, verás SyntaxError o IndentationError.
  • elif significa «si no, si…»: Python revisa de arriba hacia abajo y ejecuta solo la primera condición verdadera.
  • Con and, or y not se combinan condiciones; con in preguntas si un texto contiene a otro.
  • Para comparar se usan dos iguales (==); un solo igual asigna.
  • Recuerda que input() devuelve texto: convierte antes de comparar números.

Ya deberías ser capaz de

  • Escribir programas que toman decisiones.
  • Combinar condiciones.
  • Encontrar y corregir los errores típicos de los condicionales.

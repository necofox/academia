# Ruta de aprendizaje: Inglés desde cero

## Nivel 0 — Primeros pasos (A0)

| # | Lección | Podrás… |
|---|---------|---------|
| 01 | Saludos y despedidas (*hello, goodbye, thank you, please*) | Saludar y ser educado |
| 02 | Presentarte (*my name is…, I am from…*) | Decir quién eres |
| 03 | El abecedario y deletrear | Deletrear tu nombre y tu correo |
| 04 | Números del 0 al 100 | Decir tu edad, teléfono, precios |
| 05 | Pronombres (*I, you, he, she, it, we, they*) | Hablar de personas |
| 06 | El verbo *to be* (ser/estar): *I am, you are, he is…* | Hacer frases básicas |
| 07 | Artículos (*a, an, the*) y objetos comunes | Nombrar cosas |
| 08 | Días, meses y la hora | Decir fechas y horas |
| ★ | **Repaso y examen Nivel 0** | |

## Nivel 1 — Básico (A1)

| # | Lección | Podrás… |
|---|---------|---------|
| 09 | Presente simple (*I work, she works*) | Hablar de tu rutina |
| 10 | Preguntas y negaciones (*do / does / don't*) | Preguntar y responder |
| 11 | *There is / there are* | Describir lugares |
| 12 | Posesivos (*my, your, his, her…*) | Hablar de lo tuyo |
| 13 | Familia, comida y compras | Conversaciones del día a día |
| 14 | Verbos más comunes (*have, go, make, get, want, need*) | Expresar necesidades |
| ★ | **Repaso y examen Nivel 1** | |

## Nivel 2 — Pre-intermedio (A2)

| # | Lección | Podrás… |
|---|---------|---------|
| 15 | Presente continuo (*I am working*) | Decir qué haces ahora |
| 16 | Pasado simple (*I worked, I went*) | Contar qué pasó |
| 17 | Futuro (*will / going to*) | Hablar de planes |
| 18 | *Can, must, should* | Habilidades, obligaciones y consejos |
| 19 | Comparativos y superlativos | Comparar cosas |
| 20 | Preposiciones (*in, on, at…*) | Ubicar cosas y momentos |
| ★ | **Repaso y examen Nivel 2** | |

## Nivel 3 — Intermedio (B1)

| # | Lección | Podrás… |
|---|---------|---------|
| 21 | Presente perfecto (*I have done*) | Hablar de experiencias |
| 22 | Condicionales (*if…*) | Hablar de posibilidades |
| 23 | Voz pasiva básica (*the server was attacked*) | Leer textos técnicos y noticias |
| 24 | *Phrasal verbs* más usados (*log in, set up, shut down*) | Entender inglés real |

## Meta del curso

Usar Claude Code para crear, desarrollar, depurar y mantener proyectos con supervisión: contexto, CLAUDE.md, permisos, hooks, skills y buenas prácticas de seguridad.

- **Duración:** 5 módulos · 17 clases · 34 h de clase (2 h por clase). La práctica autónoma de cada clase se suma aparte.
- **Clases listas:** 0 de 17.
- **Siguiente clase por crear:** Módulo 1 · Clase 1: Qué es Claude Code; Chat, Code y Cowork.
- **Proyecto final del curso:** La aplicación base del equipo de agentes: una app pequeña desarrollada con Claude Code, con CLAUDE.md, permisos, un hook de protección y pruebas.
